VOTRE AGENDA PROFESSIONNEL

Connecter Microsoft 365

Votre application Microsoft est déjà configurée. Connectez-vous une fois : le dashboard retrouvera ensuite votre connexion sur cet appareil. « Déconnecter Microsoft » déconnecte l’agenda et l’intranet de ce dashboard. Si Microsoft le propose, choisissez « Rester connecté » pour conserver la session après fermeture du navigateur.

Réglages Microsoft avancés
  1. Ouvrez Microsoft Entra avec votre compte professionnel. Allez dans Identité → Applications → Inscriptions d’applications → Nouvelle inscription.
  2. Nommez l’application dashboard et choisissez Comptes dans cet annuaire uniquement (un seul locataire).
  3. Pour l’URI de redirection, sélectionnez la plateforme Application monopage (SPA) et collez l’adresse ci-dessous. Si l’application est déjà créée, ajoutez-la dans Authentification.
  4. Dans Autorisations API, ajoutez Microsoft Graph → Autorisations déléguées → Calendars.ReadBasic. Cette autorisation permet de lire les informations de base de votre calendrier. Aucun secret client n’est nécessaire.
  5. Dans Vue d’ensemble, copiez l’ID d’application (client) et l’ID de l’annuaire (locataire) dans les champs plus bas.
  6. Pour réserver l’application à votre compte, ouvrez son entrée dans Applications d’entreprise → Propriétés, activez Affectation requise ? → Oui, puis n’ajoutez que votre compte dans Utilisateurs et groupes. Un administrateur doit approuver les autorisations déléguées pour une application qui exige une affectation.

Si votre organisation bloque l’inscription d’applications ou le consentement, demandez à votre administrateur Microsoft 365 de réaliser ou d’autoriser cette configuration.

Utilisez cette adresse exacte avec la plateforme SPA.

Ces deux identifiants de configuration sont conservés dans ce navigateur. Ils ne donnent pas, à eux seuls, accès au calendrier.

VOTRE TRAVAIL, AU MÊME ENDROIT

Connecter l’intranet

Retrouvez les tâches et tickets qui vous sont attribués dans Ensemble. Leur modification reste dans l’intranet. La connexion Microsoft doit être autorisée pour votre compte.

Après connexion, le dashboard retrouve votre session Microsoft sur cet appareil. Vos tâches et tickets sont chargés à chaque visite sans être sauvegardés ici. « Déconnecter Microsoft » déconnecte aussi l’agenda.

Les identifiants Outlook sont proposés si vous les avez déjà configurés.

Fourni lors de l’activation de la connexion du dashboard dans Microsoft Entra.
